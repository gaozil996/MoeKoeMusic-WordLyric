# MoeKoe Music 逐字歌词插件

全屏歌词逐字连贯填充 + 每首歌独立的快慢微调

速度取自歌词文件本身的字内时间轴，不是均速

另外附带：歌词字体跟随应用的「字体设置 / 歌词字体」、设置页里的界面字号滑块
（80%~120%）、以及给浅色背景用的歌词描边开关。

## 安装

把整个仓库放进：

```
%APPDATA%\moekoemusic\extensions\
```

然后重启 MoeKoe Music，在 **设置 → 插件 → 刷新插件** 里启用。
