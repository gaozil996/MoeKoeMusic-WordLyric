# MoeKoe Music 逐字歌词插件

全屏歌词逐字连贯填充 + 每首歌独立的快慢微调

速度取自歌词文件本身的字内时间轴，不是均速

另外附带：歌词字体跟随应用的「字体设置 / 歌词字体」、设置页里的界面字号滑块
（80%~120%）、以及给浅色背景用的歌词描边开关。\n\n歌词页的换行不再拖尾：应用给当前行的字号加了 420ms 过渡，字号一动就必须重新断行，\n同一句歌词会先按小字号断一次再按大字号重断一次。插件把字号改成瞬时，并摘掉同一行上\n那个不能合成的 will-change:font-size；容器 600ms 的滑动缩到 180ms，离开行的淡出压到\n80ms 消掉残影。两个开关都在歌词增强面板里，默认开。

## 安装

把整个仓库放进：

```
%APPDATA%\moekoemusic\extensions\
```

然后重启 MoeKoe Music，在 **设置 → 插件 → 刷新插件** 里启用。
